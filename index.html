1. 인공지능의 개념

사람의 지적 능력을 흉내 내어 소프트웨어로 만든 것을 인공지능(AI: Artificial Intelligence)이라고 해요. 사람의 지적 능력에는 이런 것들이 있어요.

지식을 익히는 학습언어 이해와 구사이미지·소리 인식추론합리적인 판단문제 해결

그중 학습 능력은 인공지능에 많이 쓰여요. 컴퓨터는 알고리즘으로 데이터를 학습해 인공지능 모델을 만들 수 있어요. 인공지능 모델은 데이터를 학습해 만들어진 모델이고, 이 모델로 사물의 분류, 예측, 군집, 생성 같은 일을 해요.

예) 가위바위보 게임에서 손 모양 이미지를 클래스별로 학습한 모델을 만들면 승부를 내는 소프트웨어를 만들 수 있어요.

2. 인공지능의 특성

일반 소프트웨어인공지능 소프트웨어
동작 방식미리 정해진 규칙과 순서대로 동작해요.주변 환경을 학습, 인식하고 스스로 판단해 동작해요.

학습 → 인식 → 추론

인공지능은 먼저 학습하고, 학습한 것으로 새 입력을 인식하고, 인식한 결과를 이용해 추론해요. 자율주행 자동차로 세 단계를 따라가 봐요. 제목을 누르면 열려요.

① 학습: 데이터에서 특징과 패턴을 찾아 모델을 만들어요
수많은 도로 영상과 센서 데이터를 분석해 차량, 신호등, 보행자의 특징과 도로 상황의 패턴을 파악해요. 학습한 데이터의 양과 품질이 학습 결과를 좌우해요.
데이터 → 인공지능 모델
② 인식: 새 입력이 무엇인지 알아봐요
달리는 중에 카메라와 센서로 들어온 데이터를 학습한 모델로 해석해, 앞쪽 물체를 “빨간 신호등”, “횡단보도 위 보행자”로 알아봐요. 인식은 알아보는 단계이고, 어떻게 행동할지는 다음 단계에서 정해요.
새 입력 + 모델 → 알아본 결과
③ 추론: 인식한 결과와 배운 지식으로 결론을 내고 행동을 정해요
“빨간 신호등”과 “보행자”를 알아본 뒤, 학습한 지식을 이용해 “곧 멈춰야 한다”고 판단하고 속도를 줄여요. 처음 만나는 상황에도 배운 지식을 적용해요.
인식한 결과 + 학습한 지식 → 결론, 예측, 행동 결정

인공지능 기술이 적용되었을까요? (제목을 눌러 확인)

스마트폰의 계산기 (X)
수학적 규칙에 따라 계산만 해요. 이전 계산을 고려하지 않고, 새로 데이터를 학습해 예측하거나 행동하지 않아요.
마트 앞 자동문 (X)
적외선이나 동작 센서로 문에 다가오는 사람이나 물체를 감지만 해요. 주변 상황을 인식하고 판단해 행동하는 것이 아니에요.
리모컨으로 제어하는 로봇 (X)
리모컨 명령대로만 움직이고, 데이터로 만든 인공지능 모델로 판단하거나 행동하지 않아요.
로봇 청소기 (O)
센서 데이터로 주변 환경을 인식하고, 시행착오를 거쳐 최적의 청소 패턴을 만들어요.
범용 챗봇 (O)
새 정보를 학습해 계속 업데이트하고, 질문의 내용과 의도를 이해해 적절한 답변을 만들어요.
헬스케어용 스마트워치 (O)
운동량을 감지해 건강 상태를 학습하고, 맞춤형 운동과 건강 관리법을 제시해요.

실습: 엔트리로 가위바위보 AI 만들기

손 모양 이미지를 클래스(가위, 바위, 보)별로 학습시켜 이미지 분류 모델을 만들고, 코드로 가위·바위·보를 알아맞히게 해요.

준비물: 인터넷이 되는 컴퓨터나 태블릿, 가위·바위·보 손 모양 사진(모둠 친구의 손으로 미리 찍어 두기)

엔트리 열기
1. 문제 정의하기
카메라로 찍은 손 모양이 가위인지 바위인지 보인지 알아보는 인공지능 모델을 만들어요.
2. 엔트리에서 모델 고르기
[블록] - [인공지능] - [인공지능 모델 학습하기]를 눌러요. 학습할 모델 선택하기에서 분류: 이미지를 고르고 모델 이름을 정해요. 예) 가위바위보 분류 모델
3. 클래스 만들고 데이터 올리기
‘데이터 입력’에서 클래스 이름을 “가위”, “바위”로 바꾸고, 클래스를 하나 더 추가해 “보”라고 해요. 각 클래스에 해당하는 손 모양 이미지를 올려요. 엔트리는 클래스마다 5개 이상이 있어야 학습할 수 있어요. 손의 위치와 각도를 바꿔 여러 장 찍고, 세 클래스의 장수를 비슷하게 맞춰요.
4. 모델 학습하기
[모델 학습하기]를 눌러요. 학습이 끝나면 가위, 바위, 보를 구분하는 이미지 분류 모델이 만들어져요.
5. 결과에서 시험하기
‘결과’에 학습에 쓰지 않은 새 손 모양 이미지를 올려요. 어느 것으로 분류했는지 확인하고, 잘 틀리는 손 모양을 찾아봐요.
6. 모델 적용하고 코드 만들기
[적용하기]를 눌러 모델을 작품에 가져와요. “시작하기 버튼을 클릭했을 때” → 손 모양 이미지를 넣어 달라고 말하기 → “학습한 모델로 분류하기” → “만일 분류 결과가 가위(이)라면” 가위라고 말하기, 아니면 바위인지 보인지 이어서 확인해요.

3. 인공지능 시스템의 구성 원리와 문제 해결

인공지능 시스템은 인공지능 소프트웨어를 사용하여 사용자의 요구나 사용 목적 등을 달성해 주는 컴퓨팅 시스템이에요. 여러 요소가 하나의 집합으로 함께 움직여요.

인공지능 모델
데이터를 학습해 판단하는 부분
응용 소프트웨어
모델의 판단을 쓸모 있는 기능으로 바꾸는 프로그램
외부 시스템
다른 서비스나 시스템과 정보를 주고받아요.
클라우드
인터넷에 있는 서버와 저장 공간
하드웨어
스피커, 로봇 몸체 같은 실제 장치
센서
마이크, 카메라처럼 주변 정보를 받아들여요.

문제 해결 과정

문제 → 데이터 → 학습 → 인공지능 모델 → 인공지능 시스템(문제 해결)

인공지능 시스템은 주어진 문제에 대한 데이터로 인공지능 모델을 학습시키고, 학습된 모델을 사용해 지능적으로 문제를 해결해요.

학습된 모델이 하는 일

예측·분류
수치를 예측하거나 클래스를 분류해요.
예) 안구 이미지로 질환 예측, 멸종 위기 동물 분류
군집(그룹화)
비슷한 특성이 있는 것끼리 묶어요.
예) 영화 추천, 비슷한 고객 구분
인식·이해
이미지, 음성, 텍스트를 인식하고 이해해요.
예) 음성 인식, 번역, 자율주행 자동차
생성
문맥에 맞는 문장, 이미지 등을 만들어요.
예) 채팅, 문서 요약, 그림 그리기

4. 인공지능 시스템의 적용 사례

음성 인식 서비스
사용자 목소리의 음향 패턴을 처리·분석해 텍스트나 실행 가능한 명령으로 바꿔요. 스마트 홈 제어, 차량 내비게이션, 고객 서비스에 활용돼요.
추천 시스템
시청 기록, 선호도 데이터를 분석해 개인의 취향에 맞는 콘텐츠를 예측하고 추천해요. 온라인 쇼핑몰, 음악·동영상 서비스에 쓰여요.
자동 번역기
다국어 번역 및 문서로 구성된 방대한 데이터를 학습해 문맥, 의미, 문법을 이해하고 번역해요.
정보 이야기: 지능형 에이전트
복잡하고 동적인 환경을 인식하고 목표를 달성하기 위해 자동으로 행동하도록 설계된 인공지능 소프트웨어예요. 자율주행 자동차의 지능형 에이전트는 카메라와 센서로 도로 환경을 인식하고, 수집한 데이터를 분석해 속도를 조절하거나 차선을 변경해요.

활동 2. 인공지능 소프트웨어의 특징 확인하기

① 인공지능 스피커 (함께 확인)

다양한 데이터로 학습된 인공지능 스피커는 사용자의 목소리를 인식하고 응답해요.

단계 1 기능
사용자가 하는 말을 인식하고, 이에 따라 적절한 응답을 한다.
단계 2 데이터와 학습 · 어떤 데이터로 학습되었을까?
사용자의 명령이나 질문·응답을 학습하거나 인터넷에서 수집한 다양한 정보 등을 학습한다.
단계 3 문제 해결 · 우리 생활에서 어떤 도움을 받을 수 있을까?
명령에 따라 알람 설정, 스마트 홈 기기 제어 등 손쉽게 일상 작업을 할 수 있다.
일반 스피커와의 차이점은 무엇일까?
일반 스피커는 단순히 소리를 내는 장치이지만 인공지능 스피커는 음성 인식 기능과 같은 인공지능 기술을 사용하여 만든 장치이다.
어떤 인공지능 기술이 사용되었을까?
인간의 말을 이해하고 응답하기 위해 자연어 처리 기술을 사용한다.
